界面在等待解析时持续显示用时及取消，但只写等待模型返回，没有准备请求、已收到流、推理和正文阶段。此次讨论发起后转去查词与保存词条，返回时回答已经结束，因此没有完成正文流式可见性的观察。不能将源码支持 delta 或首正文时间记录等同于用户已经看见流式输出。

本轮没有修改推理强度、供应商配置或超时，也没有补造性能阶段数据。job 区间与模型调用的毫秒差额仍不包含完整点击至界面就绪的全部开销；详见[接口调查报告](french-round5-interface-investigation-2026-10-09.md)。

## 体验优化方案

以下是体验方案，尚未实施。功能 bug 仍按前述复现结果单独验收。

| 本轮体验负担 | 明确方案 | 验收条件 |
|---|---|---|
| 解析等待长，反馈只有笼统文案 | 在操作区持续呈现真实阶段与用时。收到准备、流打开、推理或正文事件时才更新对应阶段；保留取消和后台状态核对入口。记录有效 effort 后，再用相同材料比较快速与深入档的质量和时延 | 不以假进度代替事件；正文前也能辨认请求状态。提供点击到界面就绪的完整时延，不只展示模型计时 |
| 取消后需要读者自行猜测结果 | 显示正在核对，持续读取可与当前请求关联的终态；确认后显示已取消。长期无法核对时提供明确刷新入口，并保留原问题供重新预览 | 一次真实取消最终自动收敛；并发情况下不会拿旧取消消息确认新请求。R6-B02 必须独立复测 |
| 取消说明像普通模型回答 | 用独立的取消状态行显示该次请求，没有实质正文时不显示提炼结论及新回答通知；有部分正文时说明已取消、内容未完成 | 取消说明不会误触发成功提示；跳转动作指向正确分支和消息，当前页面没有目标时也有明确结果 |
| 词卡要求填写文化及固定表达 | 无资料章节默认折叠，只显示尚未收录；内部审核规则收在诊断中。继续显示读者填写、模型推断和来源信息 | 只填必要释义也能得到可阅读词卡，不显示要求补写的内部文案；未记载内容不冒充已知 |
| 首问标题过长，重复占用多处 | 自动标题压缩为词形或句法主题加短摘要；完整问题留在消息及可展开详情中。分支标签采用有限宽度，保留辨认与展开入口 | 两三个正常问题不会迫使分支条大幅横向滚动；正文、结论来源和目录能区分分支，不重复整句问题 |
| 已保存结论仍要打开路线再关闭才能阅读 | 保存反馈增加立即查看；讨论正文下给出已确认结论入口。路线选中学习节点后直接显示详情或提供明显查看操作 | 保存后无需理解路线交互也能回看；路线仍保留，但不要求额外关闭一次才能看到选择结果 |
| 上次阅读摘要重复书名章节 | 摘要由书名、章节、段落号和句号单独生成，不重复自动标题中的同一信息 | 本轮接续篇恢复摘要简短，可辨认第 02 段及第 2 句 |
